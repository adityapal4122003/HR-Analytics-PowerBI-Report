# HR Analytics Report – Power BI

## 📊 Project Overview

This project is an interactive HR Analytics Report developed using Microsoft Power BI.

The report analyzes employee data to identify workforce trends, employee attrition patterns, salary distribution, job roles, demographics, and other key HR metrics.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Employee Count | 1,480 |
| Attrition Count | 238 |
| Attrition Rate | 16.08% |
| Average Age | 37 |
| Average Salary | $6.5K |
| Average Years of Experience | 11 |

## 📈 Dashboard Features

- Employee Attrition Analysis
- Department Analysis
- Gender Analysis
- Education Field Analysis
- Age Group Analysis
- Salary Slab Analysis
- Job Role Analysis
- Business Travel Analysis
- Marital Status Analysis
- Total Working Years Analysis

## 🔍 Key Insights

- Analyzed overall employee attrition and attrition rate.
- Identified job roles with higher employee attrition.
- Compared attrition across different age groups.
- Analyzed salary distribution and employee experience.
- Examined workforce demographics including gender and education.
- Created interactive filters for HR-focused analysis.

## 🎯 Objective

The objective of this project is to transform HR data into meaningful business insights using Power BI and help organizations better understand workforce trends and employee attrition.
